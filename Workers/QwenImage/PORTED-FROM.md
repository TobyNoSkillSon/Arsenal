# Qwen-Image-2.1 native sources

Arsenal code under MIT. Written for Arsenal from the vendor's implementation as the specification; no Python runs.

- **Specification:** huggingface/diffusers `3421fed4a1655508436a5ca0c5179e88b0ec0afd` (Apache-2.0): `pipelines/qwenimage21/pipeline_qwenimage21.py` (prompt templates, system-turn drop, condition-image resize and compositing, KV-cache denoising loop, true CFG), `models/transformers/transformer_qwenimage21.py` (single-stream DiT, shared modulation, causal-condition rows, block-causal mask, 3-axis RoPE, prefix KV cache), `models/autoencoders/autoencoder_kl_qwenimage21.py` (one-frame Wan residual VAE: AvgDown3D/DupUp3D shortcuts, RMS_norm, first-chunk temporal handling) and `schedulers/scheduling_flow_match_euler_discrete.py` (exponential time shift, terminal stretch, saved Turbo sigmas). Transformers `modeling_qwen3_vl.py` for the prompt encoder (interleaved M-RoPE, deep-stack injection, `fast_pos_embed_interpolate`, `get_rope_index`) and `Qwen2VLImageProcessor` for the patch layout.
- **Adapted:** ml-explore/mlx-swift-lm `bd4b7434e6bdb588c7ef55706ff8904cb7fd4c57` `Libraries/MLXVLM/Models/Qwen3VL.swift` (MIT, `LICENSE-upstream-mlx-swift-lm`): the vision tower's interpolated position embedding, 2-D rotary layout and merger structure, and the rope-index walk, rewritten into `QwenImageNative/Qwen3VL.swift`. Local differences: the block MLP uses the configured tanh GELU (upstream hard-codes x·σ(1.702x)); the patch embedding is one matmul over the stored Conv3d kernel; image features and deep-stack features enter by row gathers; the decoder returns the last layer's output before the final norm and loads neither that norm nor the LM head.
- **Reimplemented:** Pillow 12 `src/libImaging/Resample.c` antialiased Lanczos (premultiplied RGBA, as `Image.resize` does) and Pillow's `paste`-with-mask compositing, in `QwenImageNative/ImageOps.swift`.

Weights: Qwen/Qwen-Image-2.1 and Qwen/Qwen-Image-2.1-Turbo, Qwen Research License (non-commercial), pinned in `models/qwen-image-2.1/model.toml` and `models/qwen-image-2.1-turbo/model.toml`.
