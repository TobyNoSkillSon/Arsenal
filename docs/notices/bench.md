# Bench notices

The benchmark harness, CLI, results types, validators, schemas and fixtures are original Arsenal work, licensed MIT. Swift source carries the SPDX header.

No upstream source was copied. Vella's lock thresholds and measurement conventions were consulted; the implementation is new. The harness uses Apple's Foundation/CryptoKit system frameworks and Arsenal's own Core/Wire modules, with no added third-party runtime dependency. Model weights retain the terms in their model manifests.
