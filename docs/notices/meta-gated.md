# Meta's gated models: SAM 3.1, SAM Audio Large and the DINOv3 encoders of TRELLIS.2 and IDOL

Arsenal bundles no Meta weights. SAM 3.1 (`facebook/sam3.1`), SAM Audio Large (`facebook/sam-audio-large`), the DINOv3 image encoder that TRELLIS.2 4B uses (`facebook/dinov3-vitl16-pretrain-lvd1689m`) and the one IDOL uses (`facebook/dinov3-vith16plus-pretrain-lvd1689m`) are gated on Hugging Face. Each user signs in there, accepts Meta's terms on the model's page (Meta approves each request) and gives Arsenal a Hugging Face read token; Get then downloads the pinned files from Meta's own repository with that token. Arsenal uses no re-hosted or ungated copies. Until access is granted, Get waits on the gate and says what the user has to do.

SAM 3.1 and SAM Audio Large are under Meta's SAM License; the DINOv3 encoders are under Meta's DINOv3 License. Both forbid ITAR and other trade-controlled uses, require research publications to acknowledge the materials, and require anything redistributed, including derivative works, to carry the same licence. Full texts: `Licenses/LICENSE-Meta-SAM` and `Licenses/LICENSE-Meta-DINOv3.md` in the bundle. The Swift model code for these models (Workers/Perception SAM31, Workers/Audio SAMAudio, Workers/Geometry TRELLIS.2 and IDOL) is ported from MIT-licensed MLX ports listed in each family's PORTED-FROM.md; it is distributed with these licence texts because it implements Meta's architectures.

TRELLIS.2 itself (`microsoft/TRELLIS.2-4B`, `microsoft/TRELLIS-image-large`) is MIT and ungated. IDOL itself (`speridlabs/idol`, code `speridlabs/idol-sdk`) is Apache-2.0 and ungated; its FLUX.2 VAE is FLUX.2 klein 4B's (Apache-2.0).
