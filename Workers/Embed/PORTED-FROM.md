# Embed family provenance

The family is native Swift/MLX only. No Core ML runtime, model-weight payload, Python serving code, upstream app or alternate MLX pin is bundled.

- `ml-explore/mlx-swift-lm@bd4b7434e6bdb588c7ef55706ff8904cb7fd4c57`: `Libraries/MLXEmbedders/Models/Qwen3.swift` supplies the Qwen3 attention/MLP/backbone/configuration in `QwenBackbone.swift`; `Libraries/MLXVLM/Models/Qwen35.swift` supplies the configuration and hidden-state hybrid language backbone in `OvisLanguage.swift`; `Libraries/MLXVLM/Models/Qwen3VL.swift` supplies the vision graph in `OvisVision.swift`. The public pinned `Qwen3VLProcessor` supplies patchification, resizing and normalization. Local graph wrappers add optional LM head/projector and retrieval pooling without autoregressive generation. Forward loops check cancellation between layers; copied names are isolated to Embed. Linear/Embedding eligibility is group-64, shape-based. Source checkpoint layout mappings are model-local `gate/header-map.json` files.
- `ml-explore/mlx-swift-lm@48114eedf3c3d4a682a6b1d644cc5af5c2945d10`: `Libraries/MLXLMCommon/Models/EmbeddingGemma2.swift` supplies the validated text configuration, bidirectional global/local attention spans, per-layer gates, direct RMS scales and trained output projection in `EmbeddingGemma2Text.swift`. Component/on-demand/tower interfaces from newer MLXLMCommon are removed; this adapter declares text only. The separate Gemma4 vision/audio towers and modality processors are not backported. Serving is BF16 because the maker documents FP16 activation overflow. `Libraries/MLXLLM/Models/JinaReranker.swift` supplies the projector architecture/key mapping and cosine scoring basis in `Graphs.swift` / `TextAdapter.swift`; the v3.5 behavior below supersedes v3's single-query-marker formatting.
- `jinaai/jina-reranker-v3.5-mlx@3dd4ac901ccdcac85abe3815df0a0aaaf44e4a21`: `modeling.py` and `rerank.py` are the reference for explicit per-layer sliding-window/full causal masks, the two-marker prompt, late-query pooling, 125-document blocks and weighted block fusion. The Swift implementation is local and includes no Python runtime. The model/card is CC-BY-NC-4.0; source terms not separately stated in that repo are recorded for coordinator review. Projector layouts are header-checked rather than inferred from filenames.
- `ATH-MaaS/Ovis-VL-Embedding-2B@855b64a8246cf83b34730e4470ef66949e030659`: the original flat snapshot. The weight LFS SHA256 is `7da3d68ecef45d5c8edfcbdb5c6360f15973e30d1acbf8f2548c48ee7a774797`, identical to current `ed955cc01f2d979202080f2ef2025a2a19c50b7e/model/model.safetensors`. The original flat layout is preserved by the model-owned converter. Last-token/L2 pooling and modality scope follow the card; trained prompt/processor fidelity remains a live-test risk.

`LICENSE-upstream` is the MIT licence from the pinned mlx-swift-lm source. Qwen backbones remain on that exact package and common MLX revision `901941965d82e4a216d4d117231d847d194c563d`; no dependency pin changes. Full checkpoint tensors are checked against lazy graph inventories without evaluating or downloading weights. All raw checkpoints above are BF16; manifests now declare that source dtype explicitly. Qwen/Harrier/Jina/Ovis select a model-owned `cast:embed-*-v2` recipe for a streamed FP16 base snapshot at Get; int8/int4 derive from that base. Load also accepts half source tensors through the same mapping. This is explicitly not a trained-activation FP16 qualification. Derived packs are generated in the chosen activation half, never dequantized/requantized as a new source.

The standalone family executable exists for isolated protocol smokes and binary-size inspection. Production continues through the common Native dispatcher and family symlink.

The Ovis snapshot’s `args.json` selects `qwen3_5_emb`. Its framing follows `modelscope/ms-swift@77f26d523bbfb60d974b8043ca51cc0b5660c107` (`swift/template/templates/qwen.py`, `templates/utils.py`, `base.py`): representation system instruction, native user/assistant prefix, default non-thinking prefix and `<|endoftext|>` embedding suffix. The last hidden state is pooled after this suffix, rather than after a chat assistant-end token. This is implemented in Swift using the supplied Jinja template with generation-prefix formatting and a separately appended embedding suffix; no ms-swift runtime is bundled.

The review corrections follow `huggingface/transformers@v5.12.1`, matching the pinned Ovis config: `Qwen3_5VisionMLP` uses `gelu_pytorch_tanh`; Qwen3-VL processing emits a timestamp and independent vision block per temporal group; positions split video grids accordingly. Video limits and 2 fps / 4–768 frame sampling come from the pinned `processor_config.json` video section. Its resize budget covers all sampled frames, not each image independently. Vision attention runs SDPA separately per cumulative-sequence segment, evaluates each segment and concatenates outputs, with no global square mask. Gemma and Ovis language stacks evaluate each layer before checking cancellation. Small captured reference tensors and exact framing/position/resize fixtures live under `Tests/EmbedWorkerTests/Fixtures`; no Transformers runtime is bundled. The reference functions were executed from pinned source without model weights; the copied Swift graph remains MIT and these adaptations add no Python serving dependency.

LCO-Embedding Omni 7B (`LCOAdapter.swift`, `LCOLanguage.swift`, `LCOVision.swift`, `LCOAudio.swift`, `LCOMediaIO.swift`): the Qwen2.5-Omni thinker as a last-token embedder. Module layout follows mlx-swift-lm's `Libraries/MLXVLM/Models/Qwen25VL.swift` at the pin above (MIT, `LICENSE-upstream`); numerics, the window-attention vision encoder, the Whisper-style audio encoder and `WhisperFeatureExtractor` follow transformers' `models/qwen2_5_omni/modeling_qwen2_5_omni.py` and `vision_utils.py` (Apache-2.0, `LICENSE-upstream-transformers-Apache-2.0`); prompt framing is the model repository's `additional_chat_templates/sentence_transformers.jinja` (`LCO-Embedding/LCO-Embedding-Omni-7B@108f6f1a`, Apache-2.0) and media rules follow Qwen's `qwen_omni_utils` (Apache-2.0). Modified by Arsenal: Swift/MLX, per-segment packed attention, PIL/FFmpeg/librosa-faithful media readers; no Python runtime. Qwen3-Embedding-8B uses the Qwen3 backbone listed above.
