# Kit models: sources

Each module under `Sources/` is one model's kit runner (written with `kit/runner`), bundled into the native worker. `Kit.swift` and `Wire.swift` are the kit template, `Entry.swift` replaces the runner's `main.swift`, and the model files are our MLX ports of the makers' published code; each file's header names what it follows. Weights are not code and are not here: Get downloads each model's pinned release.

Vendored code: `KitDa3metricLarge/DA3-*.swift` are the same files as `Workers/Geometry/Sources/MLXDA3` (mnmly/mlx-swift-da3@496dfb1d1f0969c5dc2518aad59ea21abb1ea88a, Apache-2.0; licence in `Licenses/LICENSE-mlx-swift-da3`, details in `Workers/Geometry/Sources/MLXDA3/PORTED-FROM.md`).

- `KitAudioboxAesthetics` (audiobox-aesthetics): Audiobox Aesthetics: a WavLM Base+ encoder (12 layers, 768 wide, gated relative position bias) with four small MLP heads, one per axis.
