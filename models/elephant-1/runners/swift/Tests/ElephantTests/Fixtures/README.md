# elephant-1 test fixtures

- `requests.json`: the nine fixed requests (four Arsenal decision bench cases, the card's ticket, nested JSON, 30 options, Polish, no instructions).
- `maker_capture.py`: the maker reference, run once: OneJev `qev` @81ce62f with the checkpoint's `serve.patch`, `DecisionEngine` on PyTorch MPS (transformers 5.19.0) in bfloat16 and float16, sequential branches. Writes `reference-<dtype>.json` (prompts, token ids, slot logits, answers, per-layer max |h|) and `components-<dtype>.json` (last-token activations) under `lab/evidence/elephant-1/maker-2026-11-02/`.
- `maker_fixture.py`: builds `maker-prompts.json` from that capture: each request as JSON text (key order kept), the maker's prompts and suffixes, its bfloat16 slot logits and the answers qev's own answer functions make from them. Read by the weight-free `PromptTests`.
- `maker_decide_mapping.py`: runs the maker's own `DecisionEngine.decide` with the forward replaced by fixed slot logits and 4 slots, so the branch plan (a 7-option choice split into chunks with the "none of the options listed here" slot) and the answer assembly are checked without weights; writes `maker-decide-mapping.json`.
- `tokenIdsAndSlotsMatchTheMaker` reads only the checkpoint's tokenizer files from the Hugging Face cache (or `ELEPHANT_TOKENIZER`) and passes without checking when they are absent.
- `media/`, `requests-mm.json`: four synthetic pictures (`maker_make_media.py`) and three picture requests: the makers' own probe screen, two traffic lights in one state, and a 50×40 sticker.
- `maker_capture_mm.py`: the makers' trained multimodal path (`train.common.batch_scores` with the readout, `train/eval_mm.py`), run once on MPS in bfloat16 and float16; writes `mm-reference-<dtype>.json` and `mm-components-<dtype>.json` under `lab/evidence/elephant-1/maker-mm-2026-11-02/`. The unpatched `qev/mm_engine.py` (causal) is recorded beside it as a diagnostic.
- `maker_mm_fixture.py`: builds `maker-mm.json` (prompts, expanded ids, prefix lengths, grids, M-RoPE positions, every 97th pixel value) for the weight-free `MediaTests`.
- `media/ball-*.png`, `media/light-*.png` (`maker_make_frames.py`) and `requests-video.json`: two short frame lists and a picture-plus-clip request; `maker-video.json` is `maker_mm_fixture.py` over the makers' video capture (`maker_capture_mm.py` run on `requests-video.json`, `lab/evidence/elephant-1/maker-video-2026-11-02/`). Read by `VideoTests`.
