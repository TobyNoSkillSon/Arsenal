# MiniMax Music 3

MiniMax Music 3 writes complete songs with sung vocals from lyrics and a music description: 44.1 kHz stereo, up to six minutes (9,000 frames at 25 per second). An 8.6B global language model (initialised from Qwen3-8B) predicts one semantic music code per frame with classifier-free guidance; a 0.65B local model fills the seven residual codebooks of that frame; the final hidden states of both are fused onto the latent timeline and condition a 2.4B flow-matching transformer, run in 200-frame windows with a 100-frame hop and overlap carry; a 54M Flow-VAE decoder (DAC-style) vocodes each window and the windows are cropped and stitched. 11.7B parameters in all, counted from the checkpoint headers.

`generate_music` takes the description as `prompt` and the words as `lyrics`, with section tags (`[intro]`, `[verse]`, `[pre-chorus]`, `[chorus]`, `[bridge]`, `[instrumental]`, `[solo]`, `[outro]`) each on its own line; text after a tag on the same line is dropped, as the maker's input contract does. For close control the maker recommends a structured caption in three parts: Global Metadata (genre, BPM, key, emotional arc, production), Vocal Details (gender, timbre, style, harmonies, effects) and Arrangement (instruments section by section). Describe the vocal explicitly, or the song may drift instrumental. `instrumental`, or leaving `lyrics` out, sends `[instrumental]` as the lyrics, the tag the maker documents (the checkpoint needs lyrics; the switch is Arsenal's). `duration` (default 60 s, from 0.04 s, one frame, to 360 s) is an upper bound: the model may end the song earlier with its end token. `steps` (default 30) and `guidance` (default 1.7) set the flow-matching Euler steps per window and its classifier-free guidance, the values the maker's pipeline exposes. `seed` makes a run repeatable on the same build. Output is one WAV per song by default; `format` offers float WAV, FLAC, M4A and ALAC, and `sample_rate: 32000` resamples to the rate the maker's own server returns. `batch_size` makes up to 16 songs one after another with consecutive seeds, at most 720 seconds of music per request in total so a batch stays inside the operation's one-hour limit; `include_metadata` adds a JSON receipt per song (frames written, whether the model ended the song, prompt tokens, seed). The prompt is limited to 5,000 tokens after assembly.

Primary source: `MiniMaxAI/MiniMax-Music3@1b525ccb685ae809f33027c51c351eeb5833cf72`. Arsenal pins only the 23 files of the diffusers layout it serves (28.5 GB): the five component directories, tokenizer, scheduler config, index files and LICENSE. The repository's other 28.8 GB (the SGLang-Omni layout `qwen_7B/`, `flowmatching_vae.pth`, `dav.pth`, figures and the demo WAV) is not needed. The language model and local model ship BF16; the fusion encoder, flow transformer and vocoder ship FP32. Get normalises every file to FP16 and then runs `cast:minimax-music3-v1`, which stores convolution kernels in MLX layout, folds the vocoder's weight normalisation and flattens its snake scales; every other tensor keeps its checkpoint name. Load casts the global language model back to BF16 and it computes in BF16, its trained dtype: its residual stream reaches 65,024 on the maker's own example prompt, at FP16's limit (`log/002-bf16-global-lm.md`). Everything else computes in FP16, the vocoder's snake activation in float32.

The Swift port lives in `Workers/Music/Sources/MusicWorker/MiniMax/` and follows the maker's diffusers integration (`huggingface/diffusers@2da7040be1a2e5f2fcbc8b985083342a308f5a86`, co-authored by the MiniMax team) step by step; mlx-audio's Python MLX port was read for structure only. Exact shortcuts: only the 16,385 rows of the global model's head that sampling can pick stay in memory (the reference masks every other row to minus infinity; this frees about 1.6 GB); the classifier-free pair runs as one batch of two, and guidance 1 runs the conditional pass alone. The fusion encoder resamples with torch's float32 nearest-index formula, and the vocoder's snake activation runs in float32 (in FP16 its 1e-9 guard vanishes). Random draws use MLX's generator, so a seed does not reproduce the maker's PyTorch output; parity is therefore checked per component on fixed tensors and by teacher forcing.

## Usage notes (2 Nov 2026)

MiniMax Music 3 writes whole songs with sung vocals. `generate_music` takes a music description as `prompt` (genre, BPM, key, vocal timbre, arrangement; a structured caption gives the closest control) and `lyrics` with section tags such as `[verse]` and `[chorus]` on their own lines; no lyrics, or `instrumental`, makes an instrumental. `duration` (0.04 to 360 s, default 60) is an upper bound the model may end before. `steps` (default 30) and `guidance` (default 1.7) tune the flow stage; `seed`, `batch_size` (up to 720 s of music per request), `format`, `sample_rate` (44,100 or the maker server's 32,000) and `include_metadata` work as in the other music models. Output is 44.1 kHz stereo. It holds about 22 GB in memory when loaded. English is what the maker's examples use; other vocal languages, Polish included, are untested. Terms: MiniMax-Music3 Community License, non-commercial in Arsenal's catalog (amber conditions line).

Parity against the maker's diffusers code on PyTorch MPS, per component on fixed inputs, all inside the frozen bound (relative L2 at most twice the maker's own FP16-vs-BF16 difference plus 0.001): global-model prefill hidden 0.010 and audio logits 0.007 (same top code, 49 of the top 50 shared), six teacher-forced frames 0.010, local-model logits 0.015, fusion encoder 0.004, flow transformer velocities 0.014 to 0.033, a full 30-step window 0.020, two spliced windows on the maker's own blocks and noise 0.012, and the vocoder 0.013 against the maker's FP16 vocoder with a float32 snake (its plain FP16 vocoder is NaN). Real checks through the isolated service: a 20-second and a 60-second song came back at full length with a normal level; in the 60-second song Parakeet heard every lyric line (the chorus twice), and the 13 joins between flow windows show no level or spectral jump beyond the song's own variation. When the given lyrics run out the model keeps singing lines of its own, so give it lyrics for the whole length you ask for. A 15-second instrumental came back with no words heard. `results/real-check-2026-11-02.md`, golden in `gate/golden/`.
